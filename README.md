# Thevindu portfolio

A personal portfolio for Thevindu Sithujaya, built with Next.js App Router, TypeScript, Tailwind CSS and GSAP for scroll animation.

## Setup

Use a supported Node.js version and pnpm, then run:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Open http://localhost:3000. For production checks, run `pnpm typecheck` and `pnpm build`.

No environment variables are required. Content and social links live in `src/components/features/portfolio.tsx`; replace `public/cv.pdf` and `public/portrait.jpg` when updated versions are available. Instagram and Facebook links have intentionally not been added until their URLs are supplied. The existing LinkedIn link and CV should be confirmed before publication.

## Search visibility

The canonical production address is `https://shadowreaper404.us`, configured in `src/lib/site.ts`. The homepage includes descriptive metadata and profile structured data; `/robots.txt` and `/sitemap.xml` are generated by Next.js. After deploying, verify the domain in Google Search Console, submit `https://shadowreaper404.us/sitemap.xml`, and use URL Inspection to check indexing. Configure the host to redirect HTTP and any `www` hostname to the canonical HTTPS address. Confirm the CV, LinkedIn URL and education details before publication, and add the portfolio URL to your real public profiles. Indexing and rankings are controlled by search engines and are not guaranteed.

## Cloudflare Pages (static export)

Create a **Pages** project connected to this repository and use:

- Production branch: `main`
- Build command: `pnpm install --frozen-lockfile && pnpm build`
- Build output directory: `out`
- Build environment variables: `NODE_VERSION=24.18.0`, `PNPM_VERSION=11.20.0`, and `SKIP_DEPENDENCY_INSTALL=1`

The explicit install uses the committed pnpm lockfile. Pages publishes the static output automatically; do not add a Wrangler or OpenNext deploy command. If the Cloudflare dashboard has a separate deploy command, that is a Workers Builds project, rather than a Git-connected Pages project. Next.js server-only features cannot run in this static export; use `pnpm dev` for local development or serve the `out` directory after building.
